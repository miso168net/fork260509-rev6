## 背景

- 憲法 §III「生成檔紀律」條的判準寫作：檔頭帶工具 Generated 標記之機器生成檔（unplugin 元件宣告 `src/typings/components.d.ts` 同族）**與 §III.2 表內「路由外掛產物四檔」同族**。
- 但 §III.2（★ 需 constitution 顯式授權軌道）在 rev6 是**空表**——創世時只搬進機制骨架與補完判準，十七用途以承襲指針列名、表體隨刀填。全 repo 對「路由外掛產物四檔」僅此一處提及，指向不存在的表列。
- 後果：讀到該句的人會去 §III.2 找一張不存在的表，判準因此不可執行。

## 決策驅動因子

- 判準句的功能是界定「哪些檔屬生成檔、禁手改」，該功能不依賴表的存在——「由路由外掛重算產出」本身就是可判的性質。
- §III.2 是授權表，填表等於授權一條新軌道（實質拍板面更大），而 base-web 路由外掛在 rev6 尚未進場，現在填屬預載。
- 憲法只走 §V.2 Amendment，且本輪已有兩筆 Amendment，可併入同一顆 commit。

## 考慮過的替代案

1. **改填實 §III.2 表**：把路由外掛產物四檔實列進去。棄——§III.2 是「需 constitution 顯式授權軌道」表，填表＝授權新軌道，實質拍板面遠大於修一句死引用；且該軌道未進場，現在填屬預載。
2. **轉 BL、首支動路由外掛的刀再處理**：棄——凍結權威文件裡的死引用是現行缺陷，本輪已有兩支 lens 各自抓到。

## 決定

1. **憲法 §III 生成檔紀律判準句改為**：「判準＝檔頭帶工具 Generated 標記之機器生成檔（unplugin 元件宣告 `src/typings/components.d.ts` 同族）**與路由外掛（elegant-router）重算產出之檔同族；具體檔集隨相關 ★ 軌道 Amendment 落表**」。
2. **語意不變**：仍是「工具重算產出、禁手改、不逐行標記、不入檔級名單」，只是不再依賴空表。
3. §III.2 維持空表；日後路由外掛軌道進場時依 §V.2 填表，屆時本句的「落表」自然兌現。

## 後果

- 憲法版本隨本輪 Amendment 一併 bump（§V.3 PATCH：文字校正／釐清）。
- 判準自此可獨立執行、不需查表；fork-delta 面的生成檔判定行為零改動。

## 翻案觸發器

- 路由外掛軌道進場並填實 §III.2 表時，重審本句是否改回引表形。
- 出現第三類「工具重算產出」檔族（非 unplugin、非路由外掛）時，判準需再擴。
