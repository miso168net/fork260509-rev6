## 背景

- ADR-00091 決定 8 為逐域差異表之單一出處；其設定域「同值出現」格＝「照寫（審計欄重寫、列版本換新）、零稽核（系統設定寫端不落稽核）」。D1 使設定寫端同交易落稽核＝該格失真；設定寫端重寫亦觸發 ADR-00091 沿用之翻案觸發器（系統設定寫端重寫或出現清空 UI 需求）。
- 設定頁之數字框清空不送、開關單次切換必變；同值寫入可經快速連續切換（第二發於回讀前送出、可與首發同值）或 API 直呼達成。

## 考慮過的替代案

1. **設定域改值 diff（同值零寫入零稽核）**——D1 字面「updateSystemSetting 同交易落一列操作日誌」（無同值例外）；否決。
2. **新增清空語意（空字串＝回 seed 預設）**——無清空 UI 需求、16 鍵皆有型；否決。
3. **不續行、只在新 ADR 記結論**——ADR-00091 決定 8 之單一出處句失真；否決。

對所選方案跑同一反例（RL-0013）：「同值寫入留稽核噪音」→畫面僅快速連切可達、API 直呼亦可達；成立而接受（D1 字面）。

## 決定

本 ADR 續行並將 supersede ADR-00091（accepted 同顆補 `supersedes: ["ADR-00091"]`、ADR-00091 status 改 superseded）。ADR-00091 決定 1～9 對應本 ADR 同號：決定 1～7 原文續行；決定 8 改寫設定域「同值出現」格、並於導句補設定寫端自本刀起讀上下文；決定 9 改寫改指對象；決定 10 新增。

8. **逐域差異表（改寫設定域）**：請求上下文缺席＝`5000` 拒寫、先於一切守門與早退（各域同；設定寫端自本刀起讀上下文）。設定域欄：可空文字欄之空字串＝設值（`description` 落空字串；續行）；JSON null＝nullable 欄落 NULL、`settingValue` null＝`2222`（續行）；除 `id` 外全缺席＝不適用（必填欄缺席＝`2222`；續行）；**同值出現＝照寫（審計欄重寫、列版本換新）、稽核 `update` 一列（前後整列快照）**（改寫）；body 缺席或壞形＝收斂後必填欄缺席＝`2222`（續行）。其餘三域各欄原文續行。
9. **現在式改指（改寫）**：現在式面 ADR-00091 改指本 ADR（機器枚舉、改完復掃）。
10. **觸發器重評結論（新增）**：系統設定寫端重寫（D1）之下，空字串語意維持——`settingValue` 逐鍵驗型與界（16 鍵皆 number 或二值 enum、空字串驗證不過＝`2222 invalidValue`）、`description` 空字串＝設值；不新增「清空」語意。

## 後果

- 設定域與角色選單域同為「同值照寫照落」；與使用者域之值 diff 刻意不同（續行）。

## 翻案觸發器

沿 ADR-00091 翻案觸發器各款（其所指 ADR-00091 決定改讀本 ADR）；另：出現設定清空 UI 需求 ⇒ 重評決定 10。
