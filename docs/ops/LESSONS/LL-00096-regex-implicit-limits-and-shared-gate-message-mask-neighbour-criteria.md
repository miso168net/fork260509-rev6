LL-00096｜既有閘加正則腿：正則內隱含之限制（錨 `^`、必含 `:`）未各算一條判準配反案或列射程外；新腿訊息與鄰腿共用字面，鄰腿既有判準之停用變異全綠存活——RL-0080 擴寫後首次再犯，碼品質審查仍跑四輪（spec-compliance-007 修單 U2；2026-10-17）

**徵狀**：spec-compliance-007 修單 U2 交付 python 工具三筆：zh-tw-lint 補避用詞、page 踢除鍵缺席改判紅、GT-12 增 redis 前綴名冊同源腿。implementer 回 done_with_escalation，自證 9 支判準變異全紅。其後規格對照 2 輪、碼品質 4 輪（fix 跑滿上限三輪，再加確認輪），共 11 支、約 152 分。各輪 blocker：
- 規格 r1 兩項：
  - rust-api 缺席時，新腿借用門鈴腿之具名跳過，但 SKIP 行與 ENV_SKIPS 理由只寫門鈴，跳過與通過在輸出上不可辨。
  - zh-tw-lint 之射程外段漏列「字節」「字符」詞境以外的裸詞形。
- 碼品質 r1 兩項：
  - 外層錨 `^RESTORE_REDIS_PREFIXES` 之行首判準無變異實證：拿掉 `^` 或容許縮排，測試皆全綠。自測所舉「行首以外之引用」樣本，實際是由 `=` 判準擋下。
  - docstring 對兩條途徑失述：`//` 註解內之常數形，與常數值在 `=` 後折行之形。
- 碼品質 r2：正則必含 `:`，`format!(` 字面無 `:` 之鍵形因此不入集合，射程外清單卻未列此形。
- 碼品質 r3：新腿與門鈴腿的外層缺席訊息同含「walkthrough-baseline.py 缺席」。門鈴腿既有案的斷言不分腿，新腿訊息即可滿足。門鈴腿「外層缺席即紅」之停用變異，在 HEAD 版會紅；加腿後，test_gates 全模組 89 案全綠存活。

**成因**：
1. RL-0080 自 2026-10-15 已含逐判準停用變異、射程宣稱逐途徑配變異，並經 `rules emit` 烤入 implementer／review／fix（RULES-VERSION `9df0bd62580d`）。implementer 對自己顯式寫出的判準都做了停用變異：集合比較、恰一處、零命中、兩錨形、接線。漏掉的是規則字面沒有點名的兩類：
   - (a) 正則內隱含之限制。錨 `^`、必含字面 `:`、字元類排除，各自都是一條判準，拿掉即放行；但它們被當成「正則的一部分」，沒有當成「一條判準」，所以既未配反案，也未列射程外。
   - (b) 與新判準共用輸出面之鄰腿既有判準。gt_12 彙整各腿輸出，既有測試以子字串斷言總輸出；新腿訊息含同一子字串，斷言即被滿足。implementer 把「每增判準即重跑」讀成只重跑自己腿的判準。
2. 規格 r1 兩筆屬同族之陳述面：一謂詞承載兩腿時，具名跳過未逐腿指名；射程外未逐途徑列舉。

**處置**：
- 規格 fix-1：門鈴腿之 SKIP 訊息與 ENV_SKIPS 理由補上新腿指名（RL-0022 同檔鏡像句），並補斷言。zh docstring 之射程外補腿③兩形，另立自測釘。
- 碼品質 fix-1：
  - 外層錨綠樣本補屬性賦值、縮排賦值兩形，殺掉「拿掉 `^`」「容許縮排」兩支變異。
  - 常數錨於 `=` 後改為 `\s*`，補四案。
  - docstring 改為逐途徑陳述。
  - zh 綠行刪去過渡期計數。
- 碼品質 fix-2：射程外補「`format!(` 字面無 `:`」形，以兩案釘住。
- 碼品質 fix-3：新腿案改為兩腿各出恰一筆、各帶腿標籤，D1 轉紅。門鈴案一行斷言改帶腿標籤屬限定外，升級主線。
- 主線收尾：
  - 門鈴案斷言改帶腿標籤；D1、D4 兩支變異於門鈴類轉紅。
  - docstring 補一句：②常數值無尾 `:` 者照取，插值處亦不補 `:` 時走查工具掃不到。
- 確認輪實跑 18 支變異，零存活。

**晉升面**：rules。user 2026-10-17 裁定擴寫 RL-0080 兩處：「判準多於一條者逐判準做停用變異（正則內之錨、必含字面與字元類排除各算一條）、每增判準即重跑（含與新判準共用輸出面〔同閘訊息、同一測試斷言〕之既有判準）」；條數不變。原判（裁定前）：主線建議擴寫此兩處，理由是三筆漏法正落在規則字面未點名之兩類；另列兩案備選，一是只記 LESSONS，二是組裝範本替 implementer 回傳加「判準×停用變異表」必填欄。提請時附證：規則塊已烤入，implementer 自證 9 支全紅。

**再犯面與守法**：寫正則判準、或於既有閘加腿時：
- (h) 正則逐成分列判準：錨（`^`／`$`／`\b`）、必含字面、字元類排除、量詞界，每一成分各配一支「拿掉即放行」之反案，或列入射程外並附承載。
- (i) 於既有閘加腿而共用彙整輸出時，先核既有測試是否以子字串比對閘的總輸出、新腿訊息是否含同一子字串。斷言改帶腿標籤，並重跑鄰腿各判準之停用變異。
