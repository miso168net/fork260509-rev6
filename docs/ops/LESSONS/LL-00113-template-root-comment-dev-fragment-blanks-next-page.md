LL-00113｜個人中心頁模板根層之修改型標記註解使該頁於開發模式成多根片段：版面 out-in 換頁過場無法完成，自個人中心點側欄他頁後內容區空白、重新整理才恢復——rev5 同形、兩代皆未察（008 刀 U18）

**徵狀**：U18 CDP（T165）旁見：自 `/user-center` 經 SPA 換頁後內容區空白、重新整理即恢復；22080（rev5）與 32080 同步驟重現相同，判「兩側同形」未計失敗。主線 CDP 重現：設定頁→個人中心→側欄點「系統設定」「使用者管理」，URL 已換而內容區零卡片零表格、console 零警告零例外。

**成因**：`base-web/src/views/user-center/index.vue` 之 `<template>` 根層先有一行 007 刀之修改型標記註解、再有根 `<div>`。Vue 模板編譯之 `comments` 選項開發模式預設保留（正式建置剝除），根層註解加元素＝多根片段；版面以 `<Transition mode="out-in">` 包路由頁，離場之頁不是單一元素根即無法完成離場，下一頁不掛載。rev5 同檔同樣把標記放在模板根層。

**處置**：U18 依 user 指令修：標記註解移入根元素內（`原行:` 計數不變、fork-delta-lint rc 0）；CDP 重驗修前空白、修後正常；spec 刻意分岔表增列。全 base-web 掃模板根層註解：路由頁只此一處（另一處為上游版面元件、不在換頁過場內）。

**晉升面**：none（候選：view-render-guard 增腿掃路由頁模板根層註解；本刀未做）。

**再犯面與守法**：
- `.vue` 模板之修改型標記放在根元素內（或腳本區、SFC 頂層），不放模板根層；改路由頁模板後以 CDP 走一次「進頁→換到他頁」確認下一頁有內容。
- 走查中「兩側同形」之異常不等於非缺陷：先以碼面判成因，再決定是否入範圍。
