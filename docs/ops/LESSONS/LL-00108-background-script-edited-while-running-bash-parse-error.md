LL-00108｜主線演練腳本背景跑全量測試期間，同 session 改了同一支腳本：bash 於續讀處解析錯、子命令退出碼成 2，而各步斷言之輸出皆已印完（008 刀 U16）

**徵狀**：008 刀 U16 之 T147 以主線演練腳本之全量子命令在背景跑全量測試，歷時約 13 分鐘。其間主線為 T148 在同一支腳本加子命令、改檔頭用法列。全量子命令各步之輸出皆已印出：全量 rc 0、測前測後存取日誌列數皆 3、兩份 diff 紀錄 cmp rc 0、jobs 檢查命令仍為空。末行卻是 `unexpected EOF while looking for matching`，子命令退出碼 2。

**成因**：bash 不先把整支腳本讀進記憶體，而是邊讀邊執行。執行中檔案被改寫，續讀位移落到新檔的另一處，解析即錯。本例的錯落在各步都跑完之後；若落在中途，後段斷言會被跳過，而前段輸出照樣正常。

**處置**：主線逐項獨立重算——兩份 diff 紀錄以 cmp 重比、自測試紀錄重算 passed／failed／ignored、現讀存取日誌列數與 `max(id)`——皆與印出值相符。T147 以重算值判定，子命令之 rc 2 記為腳本改寫所致。

**晉升面**：none（shell 執行模型之事實；守法住本檔）。

**再犯面與守法**：
- 背景執行中的腳本不改原檔：要改就另存新檔，或等完成通知後再改。
- 長跑子命令收尾印一行固定結束標記；判定時先確認標記在場，再讀退出碼。
