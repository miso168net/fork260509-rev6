LL-00097｜既有正則閘補判別案並依 RL-0080 重跑逐判準停用變異：「各算一條」之顆粒度留給各支 agent 自判——implementer 一個字元類算一條、審查員逐成員逐出現處逐 token 算，規格對照與碼品質合計十輪才收斂；RL-0080 兩度擴寫且已烤入 prompt 後再犯（maint-pre008-carriers U1；2026-10-18）

**徵狀**：maint-pre008-carriers U1 交付三件 python 小改：docsync 預算列改邏輯行口徑、GT-12 門鈴腿與 redis 前綴腿補子庫 HEAD 樹判別案與射程外句、zh-tw-lint「內置」射程外句。產品碼面只動 `references.py` 之行數函式體與預算列列名，其餘皆 docstring 與測試；`test_gates.py` 淨增約 290 行。
- 首支 run：implementer 回 done_with_escalation，自證 33 支停用變異全紅（另以 fuzz 證一支為等價變異）。其後規格對照跑滿 4 輪（fix 3 輪＋確認輪）仍有 blocker、回 unresolved，碼品質段未跑；共 8 支、約 146 分。各輪 blocker：
  - r1：外層元組字串字元類之排除成員（雙引號、換行）停用即存活；rust 兩錨之值字元類排除未做停用變異。
  - r2：外層錨右括號無殺案；三處必含字面（門鈴外層 `=`、redis 外層 `=`、常數名 `_PREFIX` 後接 `:` 之名界）停用即存活。
  - r3：rust 兩錨首段字元類之 `{`／`}` 未逐成員釘；`=` 判準「單停即計成第二錨」對「刪去」途徑不實。
  - r4（確認輪）：射程外句只列「非字面再綁定」，漏列不合錨形之字面再綁定（單引號、型別註記、縮排區塊內、條件式、隱式拼接、空元組）。
- 主線收尾改按機制列舉並補案（變異 16 支全紅）後，以續跑形重跑兩段審查；共 10 支、約 164 分：
  - 規格對照 2 輪。r1：主線收尾所列「`=` 之前折行」之途徑漏 `pub` 與 `(` 之間一形。
  - 碼品質 4 輪。r1：zh-tw-lint 反向誤中只列「內置」一詞。r2：常數名字元類 `[A-Z0-9_]` 收窄與放寬皆存活。r3：兩腿必含字面「可省」之停用變異、邏輯行空白集之 `\r`／`\f`／`\v` 皆存活。確認輪零 blocker。
- 合計 18 支、約 5.2 小時。

**成因**：
1. RL-0080 自 2026-10-17 已寫明「判準多於一條者逐判準做停用變異（正則內之錨、必含字面與字元類排除各算一條）」，本單元 prompt 經 `rules emit` 烤入（RULES-VERSION `13794b33f782`）。但「一條」的顆粒度沒有定義：implementer 以一個字元類、一個顯式判準為一條；審查員則以字元類內每個排除成員、同一字元類之每個出現處（重複段與末段）、每個必含 token（`=`、括號、`!`、引號、名界 `:`）、同一判準之「可省」與「刪去」兩途徑各為一條。每支新審查員都比前一支切得更細，於是逐輪挖出幾條。文字守法只能點名類別，定不住顆粒度。
2. r4 與續跑規格 r1 兩筆出在主線：單元定義之裁定句把射程外寫成類別詞「非字面再綁定」，implementer 照字面落地；主線收尾改按機制列舉時，又漏列一個折行位置。人工逐途徑列舉同樣受顆粒度所限，屬 LL-00076 之同族陳述面。
3. 同一支 redis 前綴腿於 spec-compliance-007 修單 U2 新建時（LL-00096）已跑過碼品質四輪；當時各輪只補被點名之判準，未對整支正則逐成分補齊，本單元重跑既有判準時，餘下之成分又逐輪浮出。

**處置**：
- 首支 run 三輪 fix：補字元類各成員之殺案（重複段與末段各釘）、右括號與三處必含字面之殺案、`{`／`}` 逐成員釘；`=` 判準之 docstring 改述「可省／刪去」兩途徑。
- 主線收尾：`_redis_prefix_findings` 射程外改按機制兩項——不合錨形之再綁定九形；錨形行為單元素而無尾逗號者（`("session")`，Python 實值為字串）照計。`_rust_redis_prefixes` docstring 補首段排除、常數值截斷與 `=` 之前折行逐途徑。新增兩案、改名一案，16 支變異全紅。
- 續跑 run 四輪 fix：
  - 補 `pub` 與 `(` 之間折行與同行空白三途徑。
  - zh-tw-lint 反向誤中改寫成腿③通則（子字串比對不辨詞界）。
  - 常數名字元類補兩向殺案。
  - 兩腿必含字面補逐 token 刪一之誘餌：門鈴 rust 側 20 形，redis 二十餘形。
  - 邏輯行空白集補逐字元殺案。
- 主線另補型別註記整段可省之誘餌（碼品質確認輪所記之唯一存活變異）。
- 清單外鏡像：`docs/ops/reference-src/code-gate-contracts.md` 之 zh-tw-lint 射程外摘要列隨腿③通則改寫。
